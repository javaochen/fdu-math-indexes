# 作者头像

站点支持在书目卡片与章节页显示作者头像。没有图片时自动显示姓氏首字徽标（如「苏」「谢」），所以**不放图也能正常显示**。

## 加一张图

1. 把图片放到本目录，建议命名 `作者拼音.jpg`（如 `su-buqing.jpg`），正面头像、正方形、400×400 左右、小于 100 KB。
2. 在对应书的 `content/<书id>/_book.md` 里加一行：

```yaml
author_img: assets/authors/su-buqing.jpg
```

3. 运行 `python tools/build.py`，刷新页面即可。

## 约定

- 路径相对于 `site/`，不要写 `site/` 前缀。
- 图片加载失败会自动退回首字徽标，不会出现破图。
- 只放**有明确授权**的图片：公有领域（作者已逝世且照片版权到期）、Wikimedia Commons 的 CC 授权、或你本人拍摄/获赠并允许公开的。
- 建议在本目录的 `CREDITS.md` 里逐张登记：文件名、作者、来源链接、授权协议。没有登记来源的图片不要提交。
