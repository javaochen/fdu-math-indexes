在本书中，如无特殊说明，默认考虑的函数是取值于广义实数集 $\overline{\mathbb{R}}=[-\infty,+\infty]$。补充定义 $\overline{\mathbb{R}}$ 的代数运算如下：对于 $a\in\mathbb{R}$，
$$(\pm\infty)+a=\pm\infty,\ \forall a\in\mathbb{R};\quad (\pm\infty)+(\pm\infty)=(\pm\infty);\quad (+\infty)+(-\infty)\ \text{无意义}.$$
$$\frac{\pm\infty}{a}=(\pm\infty)\times\frac{1}{a}=(\pm\infty),\ \forall a>0;\quad \frac{\pm\infty}{a}=(\pm\infty)\times\frac{1}{a}=(\mp\infty),\ \forall a<0;\quad (\pm\infty)\times 0=0.$$
$$\frac{a}{\pm\infty}\ \text{和}\ \frac{a}{0}\ \text{无意义}.$$

### 定义 3.1.1 @65

设 $\mathcal{R}$ 是集 $X$ 上的 $\sigma$-代数，我们常将这时的二元组 $(X,\mathcal{R})$ 称为**测度空间**。对 $X$ 中子集 $E$，其上的映射 $f:E\mapsto\overline{\mathbb{R}}^k$ 称为（$\mathcal{R}$-）**可测**是指对任意 $F\in\mathfrak{B}(\overline{\mathbb{R}}^k)$，逆像 $f^{-1}(F)\in\mathcal{R}$。

特别的，函数 $f:E\mapsto\overline{\mathbb{R}}$ 称为**可测函数**是指对任意 $F\in\mathfrak{B}(\overline{\mathbb{R}})$，逆像 $f^{-1}(F)\in\mathcal{R}$。

### 注 3.1.2 @65

由定义，我们可以看到 $E=f^{-1}(\overline{\mathbb{R}}^k)$，故 $E\in\mathcal{R}$。

### 例 3.1.3 @65

本书中，$X$ 通常是 Euclid 空间 $\mathbb{R}^k$，$\mathcal{R}$ 可取 Borel 代数 $\mathfrak{B}_k$、Lebesgue 代数 $\mathcal{L}$ 或 $\mathcal{L}_g$。例如，对 $\mathbb{R}^k$ 中子集 $E$ 上函数 $f:E\to\overline{\mathbb{R}}$，

- 考虑可测空间 $(\mathbb{R}^k,\mathcal{L}_k)$。若对于任意的 $F\in\mathfrak{B}(\overline{\mathbb{R}})$，有 $f^{-1}(F)$ 是 Lebesgue 可测集，那么我们就称 $f$ 是 **Lebesgue 可测函数**。特别的，$E$ 需是一个 Lebesgue 可测集。
- 考虑可测空间 $(\mathbb{R}^k,\mathfrak{B}_k)$。若对于任意的 $F\in\mathfrak{B}(\overline{\mathbb{R}})$，有 $f^{-1}(F)$ 是 Borel 集，那么我们就称 $f$ 是 **Borel 可测函数**。特别的，$E$ 需是一个 Borel 集。
- 由定义可知，Borel 可测函数也是 Lebesgue 可测的。
- 若取 $\sigma$-代数 $\mathcal{R}=2^{\mathbb{R}^k}$，则 $f$ 总是可测的。
- 若取 $\mathcal{R}=\{\varnothing,\mathbb{R}^k\}$，那么函数 $f:\mathbb{R}^k\mapsto\overline{\mathbb{R}}$ 是 $\mathcal{R}$-可测的当且仅当 $f$ 是常数。

在判定函数的可测性质时，常常要用到下面类型的集。设 $f$ 是 $E$ 上的广义实值函数，对于任意给定的实数 $c$，我们记

### 定义 (水平集) @66

$$E(f\ge c)=\{x\in E:\ f(x)\ge c\};\qquad E(f>c)=\{x\in E:\ f(x)>c\};$$
$$E(f\le c)=\{x\in E:\ f(x)\le c\};\qquad E(f<c)=\{x\in E:\ f(x)<c\}.$$

它们都是由 $f$ 决定的、与 $f$ 有密切联系的集。为了今后的需要，我们先对这些集的性质、运算作一些介绍，以便大家逐步熟悉这种处理方法。

### 命题 (水平集的运算关系) @66

例如它们有如下一些关系式：

1. $E(f\ge c)\cup E(f<c)=E$，$E(f\ge c)\cap E(f<c)=\varnothing$。
2. $E(f>c)\cap E(f\le d)=E(c<f\le d)$。
3. $E(f^2>c)=E(f>\sqrt{c})\cup E(f<-\sqrt{c})$（这里 $c\ge 0$）。
4. $$E(f>c)=\bigcup_{n=1}^{\infty}E\left(f\ge c+\frac{1}{n}\right). \tag{3.1}$$

这些性质，读者无须记住它，重要的是要逐步熟悉这种处理方法。

### 命题 (极限函数的水平集表示) @66

设实函数列 $\{f_n\}$ 有极限函数 $f$，那么
$$E(f\le c)=\bigcap_{k=1}^{\infty}\varliminf_{n\to\infty}E\left(f_n\le c+\frac{1}{k}\right). \tag{3.2}$$

### 注 3.1.4 @67

注意等式 (3.2) 右边的每个集改为 $E\left(f<c+\frac{1}{k}\right)$ 也是成立的，而左边的集却不能改为 $E(f<c)$。

这类由函数所产生的集的关系式可以举出很多。用点集分析的方法来研究函数时，离不开这些重要的集以及它们的关系式。例如，我们有如下的可测函数判定方法。

### 定理 3.1.5 @67

对可测空间 $(X,\mathcal{R})$ 和子集 $E\in\mathcal{R}$，函数 $f:E\mapsto\overline{\mathbb{R}}$ 是（$\mathcal{R}$-）可测函数当且仅当下列条件中任何一个成立

1. 对任意的 $c\in\mathbb{R}$，有 $E(f\ge c)\in\mathcal{R}$；
2. 对任意的 $c\in\mathbb{R}$，有 $E(f>c)\in\mathcal{R}$；
3. 对任意的 $c\in\mathbb{R}$，有 $E(f\le c)\in\mathcal{R}$；
4. 对任意的 $c\in\mathbb{R}$，有 $E(f<c)\in\mathcal{R}$。

### 例 3.1.6 @67

设 $E$ 是 $\mathbb{R}^k$ 的子集，那么它的示性函数 $f=\chi_E$ 是 $\mathbb{R}^k$ 上的 Lebesgue 可测函数当且仅当 $E$ 是 Lebesgue 可测集。这是由于 $f^{-1}((c,+\infty])$ 只可能是 $\mathbb{R}^k$，$E$ 或 $\varnothing$。

类似的，$\chi_E$ 是 $\mathbb{R}^k$ 上的 Borel 可测函数当且仅当 $E$ 是 Borel 集。

### 例 3.1.7 @67

设 $E$ 是 $\overline{\mathbb{R}}^k$ 中的 Borel 集，$f:E\mapsto\overline{\mathbb{R}}$ 是 $E$ 上连续函数。那么，$f$ 是 Borel 可测函数。

### 例 3.1.8 @67

$\overline{\mathbb{R}}^2$ 上的映射 $f(x,y)=xy$ 是 Borel 可测函数。

### 例 3.1.9 @68

设 $g:[a,b]\mapsto\mathbb{R}$ 是单调函数，则 $g$ 是 Borel 可测函数。

### 例 3.1.10 @68

设 $E$ 是测度空间 $(X,\mathcal{R})$ 中的可测集，映射 $f=(f_1,\cdots,f_k):E\mapsto\overline{\mathbb{R}}^k$ 是 $E$ 上可测函数当且仅当 $f_1,\cdots,f_k$ 是 $E$ 上的可测函数。

### 命题 3.1.11 (复合运算) @68

设 $(X,\mathcal{R})$ 是一个可测空间，子集 $E\in\mathcal{R}$，映射 $g:E\to\overline{\mathbb{R}}^k$ 是可测。若映射 $f:\overline{\mathbb{R}}^k\to\overline{\mathbb{R}}^l$ 是 Borel 可测函数，则复合映射 $f\circ g:E\to\overline{\mathbb{R}}^l$ 是可测的。

使用复合运算，我们可以获得更多的可测函数。

### 例 3.1.12 @68

设 $f$ 是 $\mathbb{R}$ 上的 Lebesgue 可测函数，则

- 令 $g(x)=|x|$。那么，$|f|$ 是 Lebesgue 可测函数。
- 令 $g(x)=|x|^p$。那么，$|f|^p$ 是 Lebesgue 可测函数。
- 令 $g(x)=\max(x,0)$。那么，$f^+\triangleq\max(f,0)$ 和 $f^-\triangleq\max(-f,0)$ 都是 Lebesgue 可测函数。容易验证 $f^+f^-=0$，$f=f^+-f^-$，而且 $f^+,f^-$ 是唯一一对满足这两个条件的非负函数。由于它们将 $f$ 分解为两个非负可测函数之差，我们称 $f^+$ 为 $f$ 的正部，$f^-$ 为 $f$ 的负部。

下面的反例说明命题 3.1.11 中的 $f$ 不可改为 Lebesgue 可测函数。

### 例 3.1.13 (不可测函数的例子) @68

设 $\Phi:[0,1]\to[0,1]$ 是 Cantor-Lebesgue 函数（定义见 1.2 节），则 $\psi=\Phi+x$ 是 $[0,1]$ 到 $[0,2]$ 的严格单调递增连续函数。从而 $\phi=\psi^{-1}$ 也是严格单调递增的连续函数，特别的 $\phi$ 是 Borel 可测函数。

由定理 2.4.7 可知，存在 Lebesgue 零测集 $A$ 使得 $\psi(A)$ 是不可测集。再令 $f=\chi_A\circ\phi$，则
$$f^{-1}(\{1\})=\{x\in[0,2]:\ \phi(x)\in A\}=\psi(A).$$
故 $f$ 不是 Lebesgue 可测函数。

### 命题 3.1.14 (可测函数的四则运算) @69

设 $(X,\mathcal{R})$ 是一个可测空间，子集 $E\in\mathcal{R}$。对 $E$ 上的可测函数 $f,g:E\to\overline{\mathbb{R}}$ 及 $\alpha,\beta\in\mathbb{R}$，

1. 若 $\alpha f+\beta g$ 点点有意义，则 $\alpha f+\beta g$ 是可测函数。
2. $fg$ 是可测函数。
3. 若 $f/g$ 点点有意义，则 $f/g$ 是可测函数。

由此可知，$\mathbb{R}^k$ 上的 Borel 可测函数或 Lebesgue 可测函数在四则运算下是封闭的。

接下来我们讨论可测函数的极限。

### 命题 3.1.15 @69

设 $(X,\mathcal{R})$ 是一个可测空间，子集 $E\in\mathcal{R}$。若 $E$ 上的可测函数列 $\{f_n\}$ 点态收敛于 $f$，则 $f$ 也是可测的。

### 注 3.1.16 @70

分析上面的讨论，我们也可以得到如下直接的证明。
$$E(f<c)=E\left(\varliminf_{n\to\infty}f_n<c\right)=E\left(\inf_{n}\sup_{m\ge n}f_m<c\right)$$
$$=\bigcup_{n=1}^{\infty}E\left(\sup_{m\ge n}f_m<c\right)=\bigcup_{n=1}^{\infty}\bigcup_{j=1}^{\infty}E\left(\sup_{m\ge n}f_m\le c-\frac{1}{j}\right)$$
$$=\bigcup_{n=1}^{\infty}\bigcup_{j=1}^{\infty}\bigcap_{m\ge n}E\left(f_m\le c-\frac{1}{j}\right).$$

上述等式也可以用 $\varepsilon$-$\delta$ 语言给出解释：$f(x)=\lim\limits_{n\to\infty}f_n(x)<c$ 当且仅当存在正整数 $n,j$，使得对任意的 $m\ge n$，我们有 $f_m(x)<c-\frac{1}{j}$。

**几乎处处** 函数的四则运算有时会在很少的点上无定义，我们可使用几乎处处的概念处理这类情况。

### 定义 (几乎处处) @70

若 $\mathcal{R}$ 是集 $X$ 上的 $\sigma$-代数，$\mu$ 是 $\mathcal{R}$ 上的测度，则称三元组 $(X,\mathcal{R},\mu)$ 是一个测度空间。对于子集 $E\in\mathcal{R}$ 和与 $E$ 中有关的命题 $A$，称某命题 $A$ 在 $E$ 上**几乎处处成立**的是指：存在一个 $\mu$-零测集 $E_0\in\mathcal{R}$ 使得在 $E\setminus E_0$ 上命题 $A$ 是成立的。

例如，对 $E\in\mathcal{R}$ 及函数 $g:E\to\overline{\mathbb{R}}$，称 $g$ **几乎处处不为零**是指存在子集 $E_0\in\mathcal{R}$ 且 $\mu(E_0)=0$，使得在 $E\setminus E_0$ 上 $g$ 不取零值；称 $g$ 是**几乎处处有限**的是指存在子集 $E_0\in\mathcal{R}$ 且 $\mu(E_0)=0$，使得在 $E\setminus E_0$ 上 $g$ 不取值 $\pm\infty$，这也等价于说
$$\mu^*(E(g=+\infty\ \text{或}\ -\infty))=0.$$

又如，称 $E$ 上函数列 $\{g_n\}$ **几乎处处收敛**于 $g$ 是指存在 $E_0\in\mathcal{R}$ 且 $\mu(E_0)=0$，使得对 $x\in E\setminus E_0$ 有 $\lim\limits_{n\to\infty}g_n(x)=g(x)$。常记之为
$$\lim_{n\to\infty}g_n=g\ \ a.e.\ \ x\in E,\quad \lim_{n\to\infty}g_n\overset{a.e.}{=}g\quad \text{或}\quad \lim_{n\to\infty}g_n\overset{\mu}{=}g.$$

### 例 3.1.17 @70

在测度空间 $(\mathbb{R},\mathcal{L},m)$ 中，若直线上函数 $f,g$ 几乎处处相等（常记作 $f\overset{m}{=}g$ 或 $f\overset{m}{\doteq}g$），那么 $f$ 是 Lebesgue 可测函数时 $g$ 也是 Lebesgue 可测函数。实际上，由于 $f\overset{m}{=}g$，故可取 Lebesgue 零测集 $E$，使得在 $\mathbb{R}\setminus E$ 上 $f=g$，从而，对任意实数 $c$，
$$\mathbb{R}(g>c)=E(g>c)\cup E^c(g>c).$$
而 $E(g>c)$ 是零测集 $E$ 的子集，故也是 Lebesgue 零测集，同时 $E^c(f>c)=E^c\cap\mathbb{R}(f>c)$ 也是 Lebesgue 可测集，故 $\mathbb{R}(g>c)$ 是 Lebesgue 可测集。这就说明了 $g$ 也是 Lebesgue 可测集。

值得注意的是，在上面的证明中我们用到了 Lebesgue 的完备性，所以这一结论对 Borel 可测函数是不成立的（能举出反例吗）！！因此，在不完备的测度空间如 $(\mathbb{R},\mathfrak{B},m)$ 中使用几乎处处的术语，要时刻注意是否会产生可测性的问题。

### 命题 3.1.18 (可测函数的四则运算) @70

设 $(X,\mathcal{R},\mu)$ 是一个完备的测度空间，子集 $E\in\mathcal{R}$。对 $E$ 上的 $\mathcal{R}$-可测函数 $f,g:E\to\overline{\mathbb{R}}$，及 $\alpha,\beta\in\mathbb{R}$，

1. 若 $\alpha f+\beta g$ 几乎处处有意义，则 $\alpha f+\beta g$ 是 $\mathcal{R}$-可测函数；
2. 若 $fg$ 几乎处处有意义，则 $fg$ 是 $\mathcal{R}$-可测函数；
3. 若 $f/g$ 几乎处处有意义，则 $f/g$ 是 $\mathcal{R}$-可测函数。

### 注 3.1.19 @71

在上面的讨论中，我们不需要对四则运算无意义的地方赋值。

在不完备的测度空间的情况（例如 $(\mathbb{R}^k,\mathfrak{B}^k,m_k)$），可在无意义的地方令取值总为 $0$，那么结论也是成立的。
