# 数学命题索引

把本科数学教材正文中有讲解的定义、定理、命题、推论与例整理成可检索、可自测的网页，正文只保留**陈述**，不含证明。教材习题按节放在独立页面，先整理泛函分析，只收题目，不添加解答。

线上：<https://javaochen.github.io/fdu-math-indexes/>

## 功能

- **手机目录**：菜单展开后可用侧栏内关闭按钮、点击外侧遮罩或 Esc 收起；选择书籍、正文或习题后自动收起，背景不跟随滚动。按节习题位于对应节标题右侧，按章习题保留在章末。

- **彩框强调**：重点应用入口、小节说明卡和小型选中项使用白底、深色文字及 2px 低饱和七彩渐变边框；深色模式也保留这些白色强调面，知识网络保持深色图面。

- **概率论开卷页**：以随机模拟、大量观测、正态极限和条件信息四个问题，引出覆盖全书 36 个已收录小节的网络，共 49 条附有说明的知识联系。点击应用可切换阅读导览，点击小节可突出直接邻居、查看联系说明并继续探索；连线不宣称严格先修。其他书的首页保持原样，章末习题的“返回本章”仍进入章节索引。检查命令：`node tests/probability_network.cjs`。

- **首页**：书目卡片总览（作者、条目数、章/节数、备注），书名为空的书标“待录入”。
- 阅读 / 卡片 / 随机三种模式。**阅读模式**下定义默认折叠，条目上的“展开/收起”可单条切换，节头“展开定义”可一键全部展开；定理与例直接显示。**卡片模式**一次只显示一条，← → 翻动，空格显示陈述。
- **独立习题页**：每节可进入对应习题页。习题以 Markdown/LaTeX 转写，保留题号、小问、完整跨页题干及书内印刷页码，不附解答；支持公式渲染、搜索和复制。已核对无独立习题与尚未录入分别显示，不并入正文卡片和随机自测。
- **章末主题分页**：概率论第 2、5 章的习题按章归属，各分为三个主题页面，不再细分。章末目录提供入口，题目始终保留原书编号；搜索定位到题目所在主题。
- **类型筛选**：每节顶部可按 定理 / 定义 / 例 / 其他 过滤，按钮上带条目数；可用 `?type=定义` 直接分享筛选视图。
- 搜索跨书全站，结果显示来源书名、节号与正文摘要；匹配时忽略 `\` 与 `$`，可以直接搜 `limsup` 这类记号。搜索结果可用 `?q=` 分享。
- **源码与复制**：条目右上角“复制”随时可取走该条的 Markdown/LaTeX（渲染模式下也可用）；“源码”换成原文查看，顶栏或 `s` 整页切换。
- **外观**：统一纸白、墨绿、暖金与七彩边框，移除旧的四套主题色和装饰辉光。顶栏保留自动／浅色／深色模式及小／中／大／特大卡片字号，选择存在本地；旧配色偏好与链接中的 `accent` 参数不再影响页面。
- 深链接 `#/书`（书首页，显示作者与全书索引）、`#/书/节`、`#/书/节/锚点`、`#/书/节/exercises`（独立习题页）；正文快捷键 `/`、`空格`、`←→`、`Shift+←→`（上/下一节）、`r`、`s`、`Esc`（退出卡片）。
- 公式按视口懒渲染，长节（60+ 条）首屏只渲染可见部分。

## 用法

```powershell
python tools/build.py                 # 从 Markdown 生成正文、习题、目录及搜索 JSON
python tools/lint.py [书id]           # 录入质量检查：页码范围、跨页缺漏、公式编号、公式内中文
python tools/status.py [书id]         # 打印各书/各章录入进度（读 books.json，不写文件）
python -m http.server 8000 -d site    # 本地预览 http://127.0.0.1:8000/
```

数据按书拆分：`books.json` 只含目录、正文条目数与习题状态/题数（首屏用），`<书>.json` 在切换书籍时按需加载，`<书>-exercises.json` 在打开已整理的习题页时加载，`search.json` 在第一次搜索时加载，包含正文和习题。校对只需书内页码，仓库不保存习题扫描图；构建与发布不需要原始 PDF。推 `main` 后 GitHub Actions 自动发布。

## 条目格式

节文件：

```markdown
---
chapter: 1
chapter_title: 度量空间
section: "1.1"
section_title: 度量空间
pages: "2–8"
---

### 定理 1.3.5 (投影定理) @29

设 $M$ 是 Hilbert 空间 $H$ 的一个闭凸子集，……
```

条目头：`### 类型 [编号] [(标题)] @书页码`。类型限
`定义 / 定理 / 命题 / 引理 / 推论 / 例 / 反例 / 注 / 构造 / 公理`。
编号可省略（无编号命题）；标题可省略。
正文空行分段，段内换行会被自动合并，可以手工折行。
公式用 `$...$` / `$$...$$`，原书编号用 `\tag{1.20}` 保留。

`build.py` 会检查：未知类型、空正文、重复锚点、`$`/`$$` 不成对。

## 内容取舍

- 正文只收**陈述**，不写证明；习题另存，按节展示，不混入正文条目。
- 习题保留原题号与小问，题数按原书大题计。保留题目自带的必要定义、条件与提示，不添加解答，不收录书后独立的习题提示与解答。
- 书上自带答案的条目（反例、构造性例子）改写成问句，**不填答案**——自测时自己判断对错。
- 无编号但有讲解的结论（Hölder、Bessel、投影定理等）照收，标题写名称。
- 原书编排中的疑点（如疑似漏写条件）照录，不改写原意，集中记在 `TODO.md`。

## 新增一本书

1. 建 `content/<id>/`，写 `_book.md`（`order` 决定切换顺序）。
2. 按节放 Markdown，front matter 填 chapter / section / pages。
3. `python tools/build.py`，推 `main`。

习题可以之后补充。未建立某节习题文件时，该节为“未录入”；只有核对过原书才能标为“无独立习题”。具体格式见 [习题整理](docs/习题整理.md)。

习题相关校验可运行 `python -m unittest discover -s tests -v`、`node tests/exercises_math.cjs` 和 `node tests/exercises_frontend.cjs`，分别检查题号/页码/题干、KaTeX 公式渲染和页面路由。路由测试使用模拟 DOM，不替代浏览器排版检查。
