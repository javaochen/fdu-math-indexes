## 功能

- **首页**：书目卡片总览（作者、条目数、章/节数、备注），书名为空的书标“待录入”。
- 阅读 / 自测 / 随机三种模式；自测时先隐藏陈述，按空格展开。
- **类型筛选**：每节顶部可按 定理 / 定义 / 例 / 其他 过滤，按钮上带条目数。
- 搜索跨书全站，结果显示来源书名、节号与正文摘要；匹配时忽略 `\` 与 `$`，可以直接搜 `limsup` 这类记号。搜索结果可用 `?q=` 分享。
- **源码与复制**：条目右上角“复制”随时可取走该条的 Markdown/LaTeX（渲染模式下也可用）；“源码”换成原文查看，顶栏或 `s` 整页切换。
- 深链接 `#/书/节`、`#/书/节/锚点`；快捷键 `/`、`空格`、`←→`、`r`、`s`。
- 公式按视口懒渲染，长节（60+ 条）首屏只渲染可见部分。

## 用法

```powershell
python tools/build.py                 # 生成 site/data/：books.json + <书>.json + search.json
python tools/lint.py [书id]           # 录入质量检查：页码范围、跨页缺漏、公式编号、公式内中文
python -m http.server 8000 -d site    # 本地预览 http://127.0.0.1:8000/
```

数据按书拆分：`books.json` 只含目录与条目数（首屏用），`<书>.json` 在切换书籍时按需加载，`search.json` 在第一次搜索时才加载。推 `main` 后 GitHub Actions 自动发布。

## 条目格式

节文件：

```markdown
---
chapter: 1
chapter_title: 度量空间
section: "1.1"
section_title: 度量空间
pages: "2–8"
---

### 定理 1.3.5 (投影定理) @29

设 $M$ 是 Hilbert 空间 $H$ 的一个闭凸子集，……
```

条目头：`### 类型 [编号] [(标题)] @书页码`。类型限
`定义 / 定理 / 命题 / 引理 / 推论 / 例 / 反例 / 注 / 构造 / 公理`。
编号可省略（无编号命题）；标题可省略。
正文空行分段，段内换行会被自动合并，可以手工折行。
公式用 `$...$` / `$$...$$`，原书编号用 `\tag{1.20}` 保留。

`build.py` 会检查：未知类型、空正文、重复锚点、`$`/`$$` 不成对。

## 内容取舍

- 只收**陈述**：不写证明，不写习题与解答。
- 书上自带答案的条目（反例、构造性例子）改写成问句，**不填答案**——自测时自己判断对错。
- 无编号但有讲解的结论（Hölder、Bessel、投影定理等）照收，标题写名称。
- 原书编排中的疑点（如疑似漏写条件）照录，不改写原意，集中记在 `TODO.md`。

## 新增一本书

1. 建 `content/<id>/`，写 `_book.md`（`order` 决定切换顺序）。
2. 按节放 Markdown，front matter 填 chapter / section / pages。
3. `python tools/build.py`，推 `main`。
