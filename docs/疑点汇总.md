# 疑点与修正汇总

汇总历次录入中子代理标注的原书疑似排印错误、识别不确定处，以及我们做过的取舍。**处理方式分三类**：

- **A 已修正**：明显是排印/OCR 错误，按数学含义改正，并在条目里保留原书说法或用括注说明。
- **B 照录**：无法确证、或改了会偏离原书，保持原样，在此登记备查。
- **C 待定**：需要你决定是否统一处理。

页码一律为印刷页码。

## 需要你决定的事项

1. **泛函附录 A–G** 是否收录（约 40 页，预计 80–120 条）。
2. **实变例 4.2.16–4.2.17** 是否补收（印刷 100，属 4.2，但超出当前 pages 范围）。
3. **弱收敛记号**统一为 `\xrightharpoonup` 还是 `\xrightarrow{w}`。
