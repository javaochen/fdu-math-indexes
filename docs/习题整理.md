# 习题整理

教材习题按节转写为 Markdown/LaTeX，网页地址为 `#/书id/节id/exercises`。校对来源只标书内印刷页码，不保存题目扫描图、PDF 页码或裁切清单。第一阶段整理泛函分析，只收题目，不添加解答。

## 收录与归属

- 每道题完整保留原题号、星号、小问、公式及必要定义。跨页题合并为一道，不能遗漏续文。
- 原书一道大题对应一个条目，小问不拆题。引用原书定理、例或前题时保留原编号。
- 不概述、不缩写题干，不擅自更改条件或原书疑似笔误；疑点另记，仍可用书内页码回查。
- 题目自带的必要定义、条件与提示保留在对应题干，不收录书后独立提示或习题解答。
- 节后习题归属原节，附录习题归属原附录。无独立习题须查过原书后显式标记，缺文件只表示尚未录入。
- 习题可搜索、复制 Markdown/LaTeX，独立于正文卡片和随机自测。

## 文件格式

每节一个文件，例如 `exercises/fanhan/01-01.md`：

```markdown
---
section: "1.1"
pages: "8–10"
status: ready
---

### 习题 1 @8

完整题干，行内公式 $...$，块级公式 $$...$$。

(i) 第一个小问。

(ii) 第二个小问。

### 习题 2 (原题标题，可省略) @8

下一题的完整题干。
```

`section` 必须与正文节 id 一致。`pages` 是整组习题在书内的印刷页码或范围；条目头 `@8` 是本题开始的书内印刷页码。无须保留 PDF 页号或图像附件。星号题可写 `### 习题 13* @89`。

确认原书无独立习题时，文件只包含：

```markdown
---
section: "A"
pages: ""
status: none
---
```

尚未录入的节不建立文件，由构建自动标记为 `unrecorded`。

泛函分析四章共 20 节及附录 C、D、E、G 有习题，附录 A、B、F 无独立习题。题数由 Markdown 自动计算，不手写维护副本。

## 校对与构建

1. 逐页读原书，完整转写每道题，合并跨页续文，核对每个小问和公式。
2. 逐题检查原题号、量词、条件、上下标、共轭、积分上下限与印刷页码。必要定义随相关题保留。
3. 运行 `python tools/build.py`，校验关联节、连续题号、非空题干、页码范围与顺序、公式定界符。
4. 运行 `python -m unittest discover -s tests -v`、`node tests/exercises_math.cjs` 与 `node tests/exercises_frontend.cjs`，检查数据、公式渲染和路由。
5. 页面检查独立习题、公式渲染、搜索定位、复制、返回正文以及无习题/未录入状态。
6. 提交源 Markdown、生成数据和相关代码；不提交原 PDF、扫描图或临时校对材料。

构建生成 `site/data/<书id>-exercises.json`，在 `books.json` 中保存各节习题状态、题数和书内页码，并将题干加入搜索索引。正文命题数与习题数分别统计。
