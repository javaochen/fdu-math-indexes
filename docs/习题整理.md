# 习题整理

教材习题按节放在独立页面，地址为 `#/书id/节id/exercises`，例如 `#/fanhan/1.1/exercises`。正文仍使用原有 Markdown 命题文件。第一阶段整理泛函分析，使用原书习题区的裁切图，只收题目，不添加解答。

## 收录与归属

- 从原书习题标题起完整保留题目，裁去前面的正文与后面的下一节正文。
- 保留原题号、原有小问、公式、配图，以及题目自带的必要定义与提示。不要将解答补入题干，不收录书后独立的“部分习题提示”或“习题解答”。
- 原书一道大题对应一道题，`(i)`、`(ii)` 等小问不单独计数。带星号的原题号仍按一道题计算。
- 跨页题要保留全部后续页，不能只收题号所在页。最后一题的末尾、必要定义及题目前后连续条件须一起核对。
- 节后习题关联原节；附录习题关联原附录，不根据内容猜测归属。将来整理章末习题时应保留原书编排，先约定归属方式再录入。
- 扫描图暂不支持题干全文搜索或文字复制，不并入正文卡片、随机与搜索范围。

## 状态

| 状态 | 含义 | 使用条件 |
| --- | --- | --- |
| `ready` | 本节习题已整理 | 题号、题数、首尾边界与跨页题均已核对，所有裁切图存在 |
| `none` | 原书无独立习题 | 已核对原书对应节，不能仅因清单为空就使用 |
| `unrecorded` | 习题未录入 | 默认状态；没有本书清单或缺少本节记录时使用 |

泛函分析四章共 20 节及附录 C、D、E、G 有习题，附录 A、B、F 已核对无独立习题。其他书尚未整理，不据此推断原书是否有习题。题数与页码只在源清单中维护，不在说明中重复维护总数。

## 源清单

每本书使用 `exercises/<书id>.json`，节键必须与正文 front matter 的 `section` 完全一致。以下仅为格式示例，实际裁切范围以已核对的源清单为准：

```json
{
  "book": "fanhan",
  "source": "泛函王凯.pdf",
  "page_offset": 12,
  "sections": {
    "1.1": {
      "status": "ready",
      "count": 10,
      "pages": "8–10",
      "scans": [
        {"pdf_page": 20, "crop": [0, 0.515, 1, 1]},
        {"pdf_page": 21, "crop": [0, 0, 1, 1]},
        {"pdf_page": 22, "crop": [0, 0, 1, 0.716]}
      ]
    },
    "A": {
      "status": "none",
      "count": 0,
      "pages": "",
      "scans": []
    }
  }
}
```

`pdf_page` 从 1 开始。`crop` 为相对于原 PDF 页的 `[左, 上, 右, 下]` 归一化坐标，取值在 0 与 1 之间；裁切框不能为空或越界。`pages` 填印刷页码，独立于正文节文件的 `pages`。泛函分析的页码换算为 `PDF 页 = 印刷页 + 12`。

习题图片由工具生成，文件名为 `site/assets/exercises/<书id>/<节id>-p<PDF三位页码>.webp`。源清单保留 PDF 页号与裁切坐标，便于回到同一版本原书重新生成、检查边界。

每张图旁的同名 `.json` 由导出工具保存尺寸、裁切坐标与图片哈希，需一并提交；构建会核对它们，防止改了清单却遗漏重新导出。导出工具需要 PyMuPDF 和 Pillow，普通站点构建只使用 Python 标准库。

## 生成与校对

1. 阅读正文节元数据与对应原书，定位习题首尾页，确认所属节及大题数量。
2. 修改本书源清单；已确认无独立习题的节写 `none`，尚未核对的节不建立记录，由构建自动标记为 `unrecorded`。
3. 运行 `python tools/export_exercises.py fanhan --pdf "../泛函王凯.pdf"` 导出图片。PDF 路径可替换为本机原书所在位置。
4. 逐页查看导出图，核对标题、大题号、小问、跨页续文、最后一题结尾；确认没有混入前后正文或书后解答。留足公式上下标的边距，不沿文字或公式笔画裁切。
5. 运行 `python tools/build.py`，检查状态、关联节、题数、页码与图片引用，并在本地预览独立习题页、返回正文及无习题/未录入空态。
6. 将源清单、图片、生成数据及相关说明一起纳入 Git。原始整本 PDF 不加入仓库。

`tools/build.py` 将习题清单转换为 `site/data/<书id>-exercises.json`，并把各节的习题状态、题数和页码写入 `books.json`。普通构建使用已保存的图片，不需要读取本机原始 PDF；只有新整理或调整裁切时才运行导出工具。

正文校验继续使用 `tools/lint.py`；它检查的是正文 Markdown，不能替代习题图像的逐页校对。
