# 提取提示词模板

给子代理派活时复制下面的模板，替换 `{{...}}` 占位符即可。模板已经把反复出错的约束写死，避免每次都靠口头交代。

本模板用于正文命题提取。习题按节另存、独立成页，整理任务改用 [习题整理.md](习题整理.md) 的流程；正文与习题任务不要共用输出文件。每本书的固有参数见文末「书目参数」。

---

## 模板正文

```
项目根目录：C:\Users\lenovo\Downloads\复旦数学本科\FDUmath_indexes
任务：从扫描版《{{BOOK_TITLE}}》（{{PDF_PATH}}）提取{{CHAPTER_TITLE}} {{SECTION_ID}}「{{SECTION_TITLE}}」的全部数学命题，写成 Markdown 文件。

【页范围】PDF 第 {{PDF_PAGES}} 页（印刷页 {{PRINT_PAGES}}）。页码偏移：PDF = 印刷 + {{OFFSET}}，条目里写印刷页码。

【步骤】
1. cd 项目根目录，运行：
   python tools/pdf_pages.py {{PDF_PAGES}} --pdf "{{PDF_PATH}}" --dpi 150 -o "C:\Users\lenovo\AppData\Local\Temp\opencode\{{SLUG}}"
2. 用 read 工具逐页查看 PNG（每次 3–4 张），完整读每一页，不要跳页。
3. 转写所有有编号的定义/定理/命题/引理/推论/例，以及无编号但书中有讲解的结论（标题写名称、不写编号）。
4. 删除全部证明与验证过程；{{EXERCISE_NOTE}}。习题不写入本次正文文件，也不要因跳过习题而将习题状态标为“原书无习题”。

【输出】{{OUT_FILE}}

front matter：
---
chapter: {{CHAPTER}}
chapter_title: {{CHAPTER_TITLE}}
section: "{{SECTION_ID}}"
section_title: {{SECTION_TITLE}}
pages: "{{PRINT_PAGES}}"
---

小标题：## [编号] 标题 [@印刷页码]（页码可省；编号可为 1.2.3、A.I、一、或无编号）
小标题按原书顺序写在该小节第一条之前，不要写成 #### 或加粗段落。
条目头：### 类型 [编号] [(标题)] @印刷页码
类型只能是：定义 / 定理 / 命题 / 引理 / 推论 / 例 / 反例 / 注 / 构造 / 公理
标题里可以包含括号，例如 `(X,\mathcal{T})`，解析器支持。
正文空行分段；行内公式 $...$，块级公式 $$...$$；原书公式编号用 \tag{{{TAG_SAMPLE}}} 保留。
中文不要写进数学模式，需要时用 \text{中文}。
反例如果书上自带构造，改成问句、不写答案（这是既定策略）。

【风格参考】读 content/{{BOOK_ID}}/ 下已有的同书文件，以及 docs/提取规范.md。

【自检】写完必须运行：
   python tools/lint.py {{BOOK_ID}}
把 lint 报出的问题逐条回去核对扫描页并修正，直到该书输出 0 条提示。
另外自查：条目头全部匹配 ^### .*@\d+$；小标题匹配 ^## .+；$ 与 $$ 成对；页码落在 {{PRINT_PAGES}} 内。
不要运行 tools/build.py（由主代理统一构建），不要 git 提交，不要改其他文件。

回报：条目数、覆盖页码、lint 结果、识别不确定处（模糊字形、跨页条目、疑似原书笔误）。
```

## 一次派多节时

- 每个子代理最多 2 节、合计不超过 25 页；再多容易漏页。
- 每个文件单独一段 `###` 序列，front matter 各自独立。
- 同一章内并行不超过 4 个子代理（受主代理串行校验限制）。

## 主代理收到结果后

1. `python tools/lint.py <书>` 应为 0 条；若子代理已修好，直接进入下一步。
2. `python tools/build.py` 看是否有重复锚点、空正文、公式不配对。
3. 抽查：每条定理/命题至少核对 1 条原文；例抽 1/3。
4. 录入数量由构建结果与 `tools/status.py` 查询，不手写 README 进度表；仅将已确认问题记入 TODO，再提交。
