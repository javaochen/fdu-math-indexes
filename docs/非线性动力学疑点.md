# 非线性动力学与混沌：录入疑点

对照翻译版（原书第 2 版）扫描页发现的原书/译本疑似问题。正文按原书照录或用括号注明，不擅自改动；需要纸本核对时按下列印刷页回查。

## 原书疑似笔误

1. **p58（3.4 例 3.4.1）**：原文说方程 $\dot{x}=-x+\beta\tanh x$ 出现“跨临界叉式分岔”，但该方程关于 $x\to-x$ 对称，$\beta=1$ 处应为超临界叉式分岔。录入时保留原问法“证明……出现跨临界叉式分岔”，未改题干。
2. **p71（3.6）**：临界曲线 $h_c(r)$ 的分母扫描作“2”，与同页推出的 $\frac{2r}{3}\sqrt{r/3}$ 不一致；录入按 3。
3. **p215（7.4 李纳定理条件 (4)）**：原文印作 $f(-x)=-f(x)$，却称“即 $f(x)$ 是偶函数”。按上下文（$|x|$ 小时负阻尼、$|x|$ 大时正阻尼）应为 $f(-x)=f(x)$；录入用后者。
4. **p155（6.3）**：“稳定结点和鞍点都属于边界情形”与同节定理（双曲不动点包含稳定结点与鞍点）矛盾，疑为译文错误；该句未录入。
5. **p320（9.1）**：式 (1) 的质量差印作 $\Delta m$，按上下文应为 $\Delta M$；录入用 $\Delta M$。
6. **p342 附近（12.1.3）**：盒维数公式中第二个极限的下标扫描作 $n\to 0$，应为 $\varepsilon\to 0$；录入保留原式并加了一句校注。
7. **p447（12.2）**：逆映射式中把“$-1$”排成上标（$x_{n+1}^{-1}$），数学上应为 $x_{n+1}-1$；录入按正确形式。
8. **p107（4.5）**：相位分离速率的条件两处都印作 $\phi=\pi/2$，按 $\sin\phi=-1$ 后者应为 $3\pi/2$；录入保留原印法并注明。
9. **p389（10.6）**：实验对照处印作 $\delta\approx 4.699$，与本节前文的 $4.669\cdots$ 不一致；疑为排版错误。
