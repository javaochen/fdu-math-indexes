| 书 | 正文页 | 估计条数 |
| --- | --- | --- |
| 高等代数 | 476 | 1000–1500 |
| 拓扑学（仅第 0–2 章） | ~230 | 700–1000 |
| 数学分析 | 804 | 1600–2500 |

以上为推测值，按每完成一章回填实测值校正。

## 建议顺序

1. 拓扑第 0–2 章（课程范围内，篇幅最小，已有 1.1 打底）。
2. 高等代数第 1–5 章，再 6–9 章。
3. 数学分析第 1–8 章，再 9–16 章。

每章完成后 `build.py` + 抽查 + 提交，站点随时可发布。
