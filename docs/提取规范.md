# 提取与校对规范

来源：`C:\Users\lenovo\Downloads\复旦数学本科\泛函王凯.pdf`（扫描版，无文本层，328 页）。
正文范围：PDF p13–p246（第一章至附录 G）；p247 起为「部分习题提示」，p269 起为另一份习题解答，均不收录。

## 收录

1. **有编号的** 定义、定理、命题、引理、推论、例。
2. **无编号但有讲解的结论**：如 Hölder、Minkowski、Young、Cauchy–Schwarz、Bessel、Riesz 表示等；条目头不写编号，`type` 用定理或命题，标题写不等式/定理名。
3. **构造性段落**：如子空间度量、乘积空间三种度量、等价度量 $d',d''$——用 `构造` 类型。

## 不收录

- 证明过程（`证明 …` 到 `□`），包括例中附带的验证计算。
- 习题（`习题 1.1` 之后的内容）、习题提示与解答。
- 纯历史/评注段落。若某段评注本身是结论（如「$C[a,b]$ 中按 $d$ 收敛等价于一致收敛」），并入相邻条目正文。
- 目录、前言、参考文献。

## 改写规则

- **反例类**：书中以「反例：……」直接给出构造的，改成问句（「举出反例：是否存在……？」），**不写答案**。
- **例**：保留构造 + 结论，删去验证过程；若验证过程本身是通用结论（如「$C[a,b]$ 完备」的证明给出等价的收敛刻画），把该结论写成一句话保留。
- **符号**：沿用原书记号；`\mathbb{R}`、`\varnothing`、`\mathfrak{G}` 等按排版还原；原书用 `≐`（几乎处处相等）写作 `\stackrel{m}{=}`。
- **术语**：保留中文译名，首次出现可附英文（Euclid、Cauchy、Hölder）。
- **页码**：填印刷页码（书页上方/下方的数字），不是 PDF 页码；两者相差 12。
- **公式编号**：原书 `(1.20)` 用 `\tag{1.20}` 保留，方便与书上对照。

## 校对清单

每节录完后：

1. `python tools/build.py` 输出 0 问题。
2. 逐条回看扫描页，核对：条件是否漏（如「非空」「闭」「有界」）、量词顺序、$\leqslant$ 与 $<$、下标范围。
3. 检查跨页条目：定理陈述被分页截断时，把两页合起来读，不要漏掉后半句。
4. 检查公式是否被识别成相似字形：`l`/`1`、`O`/`0`、`\varphi`/`\phi`、`\varepsilon`/`\epsilon`、上标 `T` 与 `\top`。

## 已知易错点

- `\max_{a\le t\le b}` 中的 `t` 易被识别成 `x`。
- 原书 `d_\infty`、`\mathbb{R}_\infty^n` 的下标是 `∞` 而非 `\infty` 的排版差异，统一用 `\infty`。
- 「几乎处处」符号 `≐` 在扫描件中易与 `=` 混淆，需结合上下文判断。
