# 提取与校对规范

本文件规定正文命题的提取与校对。扫描版（无文本层）须渲染成图片后逐页阅读；有 OCR 文本层的书也以原页图像为准。派活给子代理时用 [提取模板.md](提取模板.md)，其中的约束已覆盖本文件要点。习题按节另存并展示为独立页面，整理规则见 [习题整理.md](习题整理.md)。

## 通用规则

### 收录

1. **有编号的** 定义、定理、命题、引理、推论、例。
2. **无编号但有讲解的结论**：如 Hölder、Minkowski、Young、Cauchy–Schwarz、Bessel、Riesz 表示等；条目标题写名称，不写编号。
3. **构造性段落**：如子空间度量、乘积空间度量——用 `构造` 类型。
4. **公理/公设**：Zorn 引理、Zermelo 选择公理等按书上的地位记为 `公理` 类型。

### 不收进正文命题文件

- 证明过程（`证明 …` 到 `□`），包括例中附带的验证计算。
- 习题：另按 [习题整理.md](习题整理.md) 整理，不混入正文命题文件。书后独立的习题提示、解答不收录。
- 纯历史/评注段落；若评注本身是结论，并入相邻条目正文。
- 目录、前言、参考文献。

### 长证明拆子命题

证明整体不录，但其中的**中间断言本身是可用结论**时，要拆出来单独成条：

- 典型形态：「先证…」「只需证…」「由此得到…」「利用隐函数定理可得…」引出的引理式断言、构造出的辅助方程/变换、关键估计。
- 类型用 `命题`（或原书本身就是引理的用 `引理`），正文只写断言与条件，不写推导；**拆出来的条目一律不加编号**，标题写名称，避免与原书编号混用或占用原书将来可能出现的编号。
- 若一节正文**只有证明**（如常微分 4.4），至少把证明的逻辑骨架拆成 2–4 条，否则该节在站点上是空的。
- 判断标准：拆出来的每一条，应当能脱离开证明上下文被读懂和记忆；纯粹「因为 $x>0$ 所以…」这类中间步骤不拆。
- 本节正文若因此改动，在该节第一条加一句「下列命题由证明的中间断言整理，原书未编号」，交代来源。

### 小标题

- 原书小节内的标题用 `## [编号] 标题 [@印刷页码]`，按原书顺序写在该小节第一条之前。
- 只录原书实际存在的标题，不补编号、不改写；无编号标题直接写标题。
- 页码可省略；编号支持 `1.2.3`、`A.I`、`一、` 等形式。旧写法 `####` 兼容，新内容统一用 `##`。
- 标题与节首导语不进入搜索、卡片和自测，只在“全部”筛选下按原书顺序显示。

### 改写

- **反例类**：书上直接给出构造的，改写成问句，**不写答案**（已定策略：先不填，保留为自测题）。
- **例**：保留构造 + 结论，删验证过程；若验证过程给出通用结论，用一句话保留。
- **符号**：沿用原书记号；`≐`（几乎处处相等）写作 `\stackrel{m}{=}`。
- **术语**：保留中文译名，首次出现可附英文。
- **页码**：填**印刷页码**，不是 PDF 页码，两者差一个固定偏移（见下表）。
- **公式编号**：`\tag{1.20}` 保留原编号，便于与书上对照。

### 校对

1. `python tools/lint.py <书id>` 输出 0 条提示（页码越界/漏页、公式编号错章、公式内裸中文）。
2. `python tools/build.py` 输出 0 问题（未知类型、空正文、重复锚点、公式不配对）。
3. 逐条回看扫描页：条件是否漏（非空/闭/有界）、量词顺序、`\leqslant` 与 `<`、下标范围。
4. 跨页条目：陈述被分页截断时合起来读，别漏后半句。
5. 易混字符：`l`/`1`、`O`/`0`、`\varphi`/`\phi`、`\varepsilon`/`\epsilon`、上标 `T` 与 `\top`。

## 泛函分析（王凯）

- 源文件：`泛函王凯.pdf`，328 页；正文 p13–p246（四章 + 附录 A–G）。
- 页码偏移：**PDF 页 = 印刷页 + 12**。
- 不收录：PDF p247「部分习题提示」；p269 起另一份「习题解答」（页首标 `泛函分析 第X章解答`）。
- 正文录入进度以 `python tools/status.py fanhan` 为准，不在规范中维护副本。
- 习题：四章共 20 节及附录 C、D、E、G 按节转写 Markdown/LaTeX；附录 A、B、F 已核对无独立习题。源文件在 `exercises/fanhan/`，只保留书内印刷页码用于核对，不保存扫描图。

## 实变函数（2023）

- 源文件：`实变函数2023版.pdf`，192 页；正文 PDF p8–p192（五章）。
- 页码偏移：**PDF 页 = 印刷页 + 7**（PDF p8 = 印刷 p1）。
- 章节：1 R^k 中的集类；2 测度；3 可测函数与收敛；4 积分；5 L^p 空间。
- 不在目录里的习题小节标题是单独的「题」（PDF p19、p31、p39、p48、p56、p63、p69、p78、p86、p92、p100、p107、p114、p128、p135、p144…），正文提取时整段跳过；该书习题尚未整理，不标为“原书无习题”。
- 该书小节层级到 `1.1.1`，条目不写三级编号时仍以书上原编号为准。
- 正文录入进度以 `python tools/status.py shibian` 为准。
