# 想法（未承诺）

这里记录“可能有用但还没决定做”的方向，不是待办。要做的时候再从里面挑一条，评估成本后转成任务。

## 学习方式

### Anki 导出

- 做法：生成 CSV/apkg，正面 = 类型 + 编号 + 标题（+ 条件），背面 = 完整陈述 + 原书页。
- 成本：约 4 小时。
- 收益：把现有条目直接接进间隔重复流程，不用在网页里另造一套记忆系统。
- 风险：KaTeX 公式在 Anki 里需要 MathJax；纯 LaTeX 文本最稳，渲染交给插件。

### 引用跳转

- 做法：从陈述里抽取「由定理 X」「见例 Y」，生成锚点链接。
- 成本：约 4 小时（要处理编号在书内是否唯一：泛函按章、高代按节）。
- 收益：读证明思路、查前置结论时不用手动搜索；顺带暴露“引用了未收录条目”。
- 风险：跨书引用需人工确认，先只做同书。

### 本地复习队列

- 做法：标「会 / 不会」，按简化 SM-2（1、3、7、15、30 天）排期；首页显示“今天该复习 N 条”。
- 成本：1–2 天。
- 收益：从“随机抽”变成“该复习什么”，补上自测缺的一环。
- 风险：只存本机、换设备丢失；需要明确“不收集数据”。

### 挖空自测

- 做法：自动把关键符号（$\varepsilon$、闭、有界、$\leqslant$、下标范围）挖空，填/选后显示答案。
- 成本：1–2 天。
- 收益：比整条回忆更细，适合记定理条件。
- 风险：自动挖空可能挖到无关符号，需要“换一个空”。

### 遮住结论

- 做法：定理只显示条件，遮住「则……」之后，练“结论是什么”。
- 成本：1–2 天，主要成本是人工指定切分点（约 2000 条，可先用「则/那么/所以/故」启发式再抽查）。
- 收益：直击“会条件不会结论”。
- 风险：切分错误会误导，建议先在 1–2 章试点。

### 概念索引

- 做法：从定义标题自动生成「术语 → 定义条目」表。
- 成本：半天。
- 收益：查符号与术语比翻章节快。

### 课程范围标签

- 做法：把拓扑的课程范围标注推广到章节级，支持“只看课内”。
- 成本：半天（数据）+ 半天（筛选 UI）。

### 学习路径

- 做法：按章顺序的“今日 20 条”，带完成度。
- 成本：1 天。

### 打印 / 导出单节

- 做法：CSS 打印样式，或将一节导出为 PDF。
- 成本：半天。
- 收益：不确定，取决于是否真的打印。

## 视觉与交互（另见讨论）

- 陈述改用中文衬线，和 KaTeX 的西文衬线统一。
- 条目卡去掉边框，改用细分隔线，提高信息密度。
- 类型用左侧小色条 + 文字标签，避免“彩色墙”。
- 节标题吸顶，滚动时始终可见节号与条目数。
- 移动端底部模式栏。
