- 源文件：`非线性动力学与混沌.pdf`，515 页，12 章。**PDF = 印刷 + 17**（PDF 18 = 印刷 1、PDF 224 = 印刷 207）。
- 翻译版·原书第 2 版，孙梅等译。OCR 文本层质量差（「混沌」常识别为「棍沌」），一律以页面图像为准。
- 收录范围：第 2–12 章正文，共 68 节。跳过第 1 章（概述与历史）与各章 `x.0 引言`（纯叙述）。
- 本书以「例题」为主体，编号定理集中在第 6–8 章。**例题只留题干，不附解答**；例题解答中的通用判据与结论拆成无编号 `命题` / `注`。
- 图是正文的一部分，站点不收图，条目保留「图 x.y.z」引用与必要的一句话说明。
- 章末「第 X 章 练习题」为整章习题，尚未整理；今后按章建 `exercises/feixianxing/XX.md`（参考概率论章末习题的 `chapter` 写法）。
